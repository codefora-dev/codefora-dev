## Current Codefora focus

Codefora is evolving from the original Dokan Buddy integration into a connected
ecosystem of independently owned products. Current work includes a reusable
administration environment, product-supplied identity and capability contracts,
developer diagnostics, marketplace tooling, and the architectural Foundation
that keeps those systems coherent.

Each product should be useful on its own. Relationships between products should
be explicit, optional where possible, and governed by the product that owns the
underlying responsibility.
